# 2026年9月免费与低价服务器清单：哪些真免费、哪些已在薅羊毛路上停了

一年多前那份"免费 VPS 大全"里，至少有三个条目现在点进去是打不开的。免费云服务的政策变化比大多数人预期的快——Heroku 的免费 Dyno 早在 2022 年底就关了，ClawCloud Run 在 2026 年停止运营，Scaleway 被广泛传的"免费云服务器"从来就不存在计算实例免费层。

这篇按 2026 年 9 月的实际情况重新核实一遍，把"永久免费""试用金""已停或不实"三类分开，再补上国内的低价年付方案。判断标准只有一句：**看到"免费 VPS"，先问三个问题——是永久免费还是试用？要不要信用卡？会不会休眠？**

## 一、真·永久免费：只有几个值得认真看

### Oracle Cloud Always Free —— 目前唯一的重量级答案

如果要的是"真独立服务器且永久免费"，Oracle 是现阶段绕不开的选择，也是这份清单里唯一能给到实打实资源的：

- **2 台 AMD 虚拟机**（各 1/8 OCPU + 1GB 内存）
- **最多 4 台 ARM 虚拟机**（Ampere A1，合计 24GB 内存）
- **200GB 块存储**
- **10TB/月 出口流量**

24GB 内存的 ARM 实例拿来做个人博客、导航站、Docker 实验、甚至跑几个小型服务都够用。代价是需要一点 Linux 运维能力，而且账号开通偶尔"抽风"——尤其是 ARM 资源紧张时反复提示容量不足，耐心多试几个可用区通常能开出来。ARM 实例还要注意选 ARM 兼容的镜像。

### Google Cloud Free Tier —— 单台微实例，限美区

GCP 的永久免费层里最实用的是 **1 台 e2-micro 实例**（限美国特定区域），外加 5GB 云存储和 20 多项永久免费服务。另外新用户还有 300 美元、90 天的试用金。

要分清的是：**"赠送额度"和"永久免费"是两套东西**。e2-micro 是永久免费的，但一旦选了别的区域或更大规格，立刻开始按量计费。Cloud Run 有每月 200 万请求的免费额度，是 serverless 场景更划算的入口。

### 零门槛的网站托管（不是 VPS，但够用）

如果只是想把网站挂起来，其实不需要 VPS：

| 服务 | 免费内容 | 关键限制 |
|---|---|---|
| alwaysdata | 1GB SSD + 256MB RAM + 免费邮箱 | 共享托管 + SSH，非独立 VPS |
| InfinityFree | 无限空间/带宽 + 免费 SSL + 400 个 MySQL | PHP 虚拟主机，无 SSH，无备份 |
| 000WebHost | 300MB + 3GB 带宽 | 每天休眠 1 小时，不适合公开业务站 |
| GitHub Pages / Netlify | 静态站托管 | 仅静态，无后端 |
| PythonAnywhere | Python Web + 子域名 | CPU/存储/流量受限，仅子域名 |

## 二、试用金：金额大 ≠ 白嫖久

这一类最常见的误解是看到"$200 免费额度"就以为能用很久。实际看两个维度——金额和有效期：

| 服务 | 试用额度 | 有效期 |
|---|---|---|
| AWS | Credits（约 12 个月） | 12 个月后转付费 |
| Azure | $200 信用 + 40+ 项永久免费 | 信用 30 天 |
| Google Cloud | $300 | 90 天 |
| DigitalOcean | $200 | **60 天** |
| Vultr | $100 | **30 天** |
| Linode（Akamai） | $100 | 60 天 |
| UpCloud | $25 | 30 天 |

DigitalOcean 的 $200 看着最多，但 60 天到期；Vultr 的 $100 只有 30 天。**金额除以天数**才是真实的"每天白嫖额度"，这么一算各家差距并不大。

另外两点容易踩的坑：

1. **几乎所有试用金都要信用卡预授权。** 不实际扣款，但会占额度，且有卡片被风控拒绝的概率。
2. **AWS 已转向"信用点"模式。** 新账号拿到的是有限期信用点，而不是早期那种无条件的一年期免费套餐。注册前看清拿到的是"信用点"还是"逐项免费"。

## 三、已停 / 不实：别再照着老列表注册

这是最需要更新的一部分，网上流传的清单里这几条已经失效：

| 服务 | 原说法 | 2026 年真实情况 |
|---|---|---|
| Heroku Free Tier | 免费 Dyno | ❌ 2022 年 11 月已永久关停，最便宜 Eco dyno $5/月 |
| ClawCloud Run | 每月 $5 永久免费 | ❌ **2026 年已停止运营**，官网不可访问 |
| Scaleway | 免费云服务器试用 | ❌ 无计算实例免费层，最低 STARDUST1 ≈ €1.83/月 |
| Google App Engine 旧代 | "永久免费" | ⚠️ 额度已大幅收紧，以 GCP Free Tier 为准 |
| FreeVPS 类分享站 | 各类免费 VPS | ❌ 多为测试账号，稳定性与合规风险高 |

ClawCloud Run 尤其值得提一句：它曾经是少数"无需信用卡 + 持续免费"的例外，被不少人当作长期方案，但现在已停服，历史教程全部作废。

## 四、愿意花一点钱：国内低价年付方案

对于用户主要在中国大陆的场景，几十块到一两百块一年的轻量应用服务器，往往比死磕免费方案更省心。国内厂商的常规玩法是：

- **新用户年付优惠**：阿里云、腾讯云等常年有轻量应用服务器的新客年付活动，2 核 2G 配置的入门档经常在几十元到一百多元/年的区间，具体价格随活动波动，需要以当期活动页为准。
- **云厂商免费试用中心**：阿里云有独立的免费试用中心（free.aliyun.com），覆盖云服务器、数据库、函数计算等，适合先跑通再决定是否付费。
- **学生认证优惠**：多数国内厂商对学生有额外折扣，认证流程通常几分钟。

国内方案真正的优势不在价格，而在**中文后台 + 中文文档 + 报错能搜到中文教程**。对第一次接触服务器的人来说，这个优势比省下的几十块更值钱。

## 五、为什么"配置很高"的服务器还是慢

这是新手最容易踩的坑。看到 8 核 16G 100G SSD 就觉得要起飞，结果国内打开一直转圈。

问题往往和 CPU 无关。**如果服务器在海外、用户在中国大陆，网络线路对体验的影响远大于多两个 CPU 核心。** 两台都在美国的服务器，配置完全一样，但走 CN2 GIA、联通优化、CMIN2 线路的和走普通国际出口的，晚高峰表现可能是两个世界。

服务器行业很反直觉的一点：**表面卖的是 CPU 和内存，真正决定体验的经常是网络那一段。**

## 六、避坑清单

1. **删机不等于删盘。** AWS/GCP 删除实例经常不自动删磁盘，遗留卷持续计费——这是新手最常见的意外账单来源，务必手动清理，并设预算告警。
2. **出口流量是隐藏杀手。** 免费层对 egress 限制普遍很严，图片、视频、大响应会很快超额。
3. **休眠是常态。** 免费层的项目大多会在无访问后挂起，不适合做生产服务。
4. **免费服务器真正贵的可能是时间。** 为了省 100 块，花半天研究申请、迁移、配 SSL、导数据库，时薪算下来并不划算。

## 结语：一个简单的选择框架

- **只是学 Linux / Docker / 建站折腾** → Oracle Always Free 优先，或 GCP e2-micro。
- **想零门槛写代码部署** → Cloud Run、Vercel、Netlify。
- **只想免费放个网站** → InfinityFree / 000WebHost，或直接 GitHub Pages。
- **短期测试大厂云** → 挑一个离用户近的试用金，记得看有效期。
- **准备长期运营** → 别为省几十块牺牲稳定性和数据。这时候该问的是 IP 稳不稳、线路好不好、有没有备份、出问题有没有人管。

**测试项目看价格，正式项目看时间成本。** 服务器只是工具，网站能不能被访问、能不能带来价值，才是正事。
