> **一个判断原则**：优惠信息要带**截止日期**。没有截止日期的"促销"，本质上就是无法验证的过期信息。

## 三、为什么能这么便宜？

一台机器卖到 $0.58/月，显然不是在亏本做慈善。便宜的来源是**四个真实存在的成本压缩**，理解它们才能理解坑在哪里。

### 1. 超售（最核心）

虚拟化技术允许宿主机对 CPU 和内存**超额分配**。一台物理机有 64 核，可以卖给 200 个"2 核"实例——只要不是所有人同时满载，表面上都正常。你付的是"标称配置"，拿到的是"别人不用时的剩余算力"。

**识别方法**：登录后立刻看 CPU 窃取时间（Steal Time）。

```bash
vmstat 1 10      # 看 %st 列
top              # 看 %st 列
```

`%st` 长期大于 **5%** 说明宿主机开始过载；经常冲到 **20%–50%**，就是严重超售——你跑任何脚本都会莫名卡顿。

### 2. 网络：普通线路 + 共享带宽

低价机的默认线路是普通国际公网（电信 163、联通 4837），**晚高峰（北京时间 20:00–23:00）丢包率可能超过 30%**。宣传的"1Gbps"是**共享端口**，几百个实例抢一条线。

真正的精品线路（电信 **CN2 GIA**、联通 **AS9929**、移动 **CMIN2**）价格通常是普通线路的 2–3 倍。1 美元/月的机器**不可能**给你 CN2 GIA。

还有个细节：商家宣传"电信直连"通常只指**去程**，而真正影响你下载速度的**回程**可能绕道欧洲再折返。

### 3. 机房与硬件

二三线机房、自建机柜、消费级 SSD、RAID 配置缩水——这些都是成本项。低价机的 4K 随机写 IOPS 在高负载下可能跌到几十，出现数秒的 I/O 阻塞。

### 4. 人力：Unmanaged + One-man

绝大多数低价商家是**纯自助运维**（Unmanaged）：系统故障自己修，不提供应用层支持。不少是一两个人兼职运营，没有 7×24 工单，没有合规机房租赁合同。

### 5. 商业模型：首年引流，续费涨价

这是最需要记住的一点。**低价是获客成本，不是常态定价。** 首年 $10 的套餐，第二年续费 $24–36 是行业惯例（2–4 倍）。有些商家（如 RackNerd）承诺"续费不涨价"，但这是口碑优势而非常规。

## 四、优势：它确实解决了真问题

抛开风险，低价 VPS 的价值是实打实的：

- **试错成本趋近于零**。一年十几美元，学 Linux、练 Docker、跑个监控代理、搭个 Telegram bot，比买任何课程都划算。
- **不用备案**。海外机房对个人项目友好。
- **支付门槛低**。支付宝直付，不需要信用卡。
- **部分老牌确实稳**。RackNerd（2015 年成立）、EthernetServers（2013 年成立）在低价圈口碑长期稳定，属于"便宜但不坑"的类型。

**适合的场景**：学习环境、个人博客、监控代理、爬虫、Telegram bot、跳板机、临时测试、备份存储。

## 五、坑：便宜在哪里，代价就在哪里

| 坑 | 具体表现 | 规避 |
|---|---|---|
| **超售** | `%st` 长期 >5%，脚本莫名卡顿 | 开机 24 小时内跑 `vmstat` 验机 |
| **晚高峰炸线** | 白天满速，晚上 20:00 后寸步难行 | 晚高峰实测，别只看白天测速 |
| **续费涨价** | 第二年账单是首年 2–4 倍 | 到期前 7 天决定去留，关掉自动续费 |
| **脏 IP / 被墙** | 开机就访问不了国内 | 24 小时内提工单免费换，**别先重装系统** |
| **换 IP 收费** | $3–5/次 | 下单前确认 ToS 里的换 IP 政策 |
| **ToS 严苛** | CPU 长期超 30% 被关机甚至封号 | 别把它当计算型机器用 |
| **OpenVZ 限制** | 共享内核、不能跑 Docker、改不了内核参数 | 不确定就**只买 KVM** |
| **无退款** | 促销套餐常注明不支持退款 | 首次先买最短周期试水 |

**关于 IP**：商家 ToS 通常写明"IP 无法访问中国大陆不属于硬件故障"。多数老牌商家在**开机 24 小时内提供一次免费更换**，发现被墙就立刻开工单，标准话术：

> The allocated IP is unreachable from China upon deployment, please kindly help to reassign or replace the IP.

**关键：先开工单，别急着重装系统**——重装会被视为"已使用"，可能失去免费更换资格。

## 六、跑路：2026 年的真实案例与识别方法

2026 年中文圈的 VPS 停运消息格外密集：

- **爪云 Claw.Cloud** —— 主动关停
- **狐蒂云** —— 资金链断裂，进入破产清算
- **Upstream Network** —— 停运
- 另有一批小厂被资方整合收编

### 出事前的共同信号

1. **买断制 / 超长预付**。"终身套餐""三年付五折"——一次性收大笔钱，本质是在借未来的现金流。这是最强的危险信号。
2. **价格击穿成本线**。独立 IPv4 的年度成本是客观存在的，**任何标价低于 $10/年还承诺大内存大带宽的，要么极端超售，要么是随时可能断粮的个人灵车**。
3. **成立时间短**。运营不足 2 年、没有历史口碑可查。
4. **节假日前疯狂促销**。"五一前圈钱""双 11 前大促"——在已知的资金压力点前集中收钱，需要警惕。
5. **无公司实体**。WHOIS 隐私保护、无注册公司、无固定办公地址。
6. **工单失联**。响应从数小时变成数天，是资金或人力出问题的早期征兆。

### 实操排查清单

下单前花五分钟做四件事：

1. **查 WHOIS**：域名注册多久了？隐私保护？注册年限只有一年的要留心。
2. **查 ASN**：是真有自营机房，还是从别家转租的二级代理？转租链条越长，跑路概率越高。
3. **搜口碑**：在 LowEndTalk、V2EX、Hostloc 搜商家名 + "跑路/倒闭/坑"。**特别关注近 3 个月的帖子**。
4. **看退款条款**：无退款 + 超长预付 = 最危险的组合。

### 三条防御习惯

- **只买年付，不买多年付。** 年付已经是可接受的风险敞口，三年付把风险放大了三倍。
- **关键数据异地备份。** 用 Restic 加密增量备份到 Backblaze B2 或 Cloudflare R2，1TB 月费不到 6 美元。**假设商家明天消失，你的数据也不该丢。**
- **用虚拟卡或单独 PayPal 限额。** 避免主卡被续费高价扣款。

## 八、什么时候不该用廉价 VPS

**这条比上面所有技巧都重要。**

廉价 VPS 适合**非关键、可重建、无 SLA 要求**的负载。以下场景**不要用**：

- **承载付费用户的生产服务**。注册、登录、支付一旦挂了，1 美元机器可能 30 分钟都没人响应。
- **存储不可恢复的数据**。小厂跑路、硬盘故障导致数据丢失的事故每年都有。
- **需要稳定 IP 且不能更换的服务**。域名解析、邮件 MX 记录——IP 一变就是灾难。
- **对延迟敏感的国内访问服务**。低价机拿不到 CN2 GIA，晚高峰体验会很差。

这些场景应该用 Hetzner、OVH 这类大厂，或者直接选国内云。**省下的几十块，远不值一次事故的代价。**

## 结语

1 美元/月的 VPS 是真实存在的，它的便宜来自**超售、普通线路、二线机房和自助运维**这四件事的叠加。它不是骗局，但它有明确的适用边界：**放能重建的东西，做能重来的事。**

三条最该记住的：

1. **看截止日期。** 中秋的促销今天就该下架，双 11 的还没开始。优惠信息的价值随时间衰减得极快。
2. **验机再付款不是选项，是必需。** `vmstat` 看 `%st`，晚高峰 `ping` 看丢包，这两条能筛掉大部分坑。
3. **假设它会跑路。** 数据异地备份、只买年付、用限额支付——做好这三件事，跑路对你就是"换一家"而不是"灾难"。
